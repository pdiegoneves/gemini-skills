# Template — Relatório A3 (A3 Problem Solving)

**Quando usar:** contar, em uma página, a história completa de um problema — do sintoma à causa raiz, à contramedida, ao resultado. É a ferramenta padrão de coaching Lean (Toyota/Lean Enterprise Institute) — menos rigor estatístico que DMAIC, mais estrutura que um 5 Porquês solto. Estrutura em 7 seções, seguindo PDCA: seções 2–6 são o "Plan", seção 7 é "Do-Check-Act".

**Como conduzir com o usuário:** preencha uma seção por vez, na ordem. Não avance para "Causa Raiz" sem dados na "Condição Atual". Não aceite contramedida sem causa raiz identificada.

---

## Cabeçalho
- **Título** (nomeie o gap, não a solução — ex: "Tempo de ciclo na Linha 3 está 28% acima do takt", não "Instalar novo dispositivo na Linha 3")
- Autor / Coach / Área / Data de abertura / Nº de revisão

## 1. Contexto (Background)
3–5 frases: por que este problema importa para o negócio/cliente agora?

## 2. Condição Atual (Current Condition)
Mostre o problema com dados, não opiniões. Esboce o fluxo (simples ou swimlane), marque onde a falha ocorre, inclua números: frequência, taxa de defeito, custo, reclamações de cliente.
- *Pergunte ao usuário: "Você tem os dados reais, ou preciso marcar como 'a levantar'?"*

## 3. Meta / Objetivo (Goal)
Estado futuro mensurável, com prazo. Formato: "Reduzir [métrica] de [X] para [Y] até [data]."

## 4. Análise de Causa Raiz (Root Cause Analysis)
Use 5 Porquês e/ou Ishikawa (ver `5porques-ishikawa.md`). Causa raiz aterrissa melhor num diagrama de espinha de peixe do que numa lista com marcadores.

## 5. Contramedidas (Countermeasures)
Lista de ações específicas, cada uma endereçando uma causa raiz identificada (não o sintoma). Dono e prazo em cada item.

## 6. Plano de Implementação / Confirmação de Efeito
Cronograma de quem faz o quê e quando. Como e quando você vai medir se funcionou (mesma métrica da Meta).

## 7. Acompanhamento (Follow-up)
O que ficou pendente, o que virou padrão (atualizar Trabalho Padrão se aplicável), próxima revisão agendada. Trate isto como item de pauta recorrente — A3 sem follow-up para na contramedida e nunca confirma efeito real.

---

**Disciplina do formato:** se a explicação de qualquer seção não cabe no espaço de uma folha A3, o problema ainda não foi suficientemente compreendido para agir sobre ele. A restrição é o rigor, não burocracia.
